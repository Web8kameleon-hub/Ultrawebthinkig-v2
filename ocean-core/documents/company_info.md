## Çfarë është Clisonix Cloud?

Clisonix Cloud është platformë industriale AI e ndërtuar nga Ledjan Ahmati / ABA GmbH.
Ofron analiza EEG, audio binaural, ML pipelines, dhe AI agents për industri dhe shkencë.

## Motorët (Engines)

- **Ocean (Curiosity Ocean)** — AI chat & knowledge engine, truri i platformës
- **ALBA** — Audio & EEG analysis engine (port 5555)
- **ALBI** — Neural biofeedback engine (port 6680)
- **ASI** — Advanced System Intelligence, real-time analytics
- **JONA** — Industrial IoT gateway
- **Cycle Engine** — Data cycle processing & alignment

## Teknologjia

- Backend: FastAPI microservices (Python)
- Frontend: Next.js (apps/web)
- AI/ML: Ollama (local LLM), PyTorch, HuggingFace, vLLM
- Infrastructure: Docker Compose, GitHub Actions CI/CD, Hetzner Cloud
- Data: Redis, PostgreSQL, real-time streaming

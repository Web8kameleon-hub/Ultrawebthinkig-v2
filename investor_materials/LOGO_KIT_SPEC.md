# Clisonix Logo Kit Spec

## Purpose
This document defines the minimum logo asset package required for investor materials, press kits, and partner integrations.

## Required Deliverables
- Primary logo (horizontal): `clisonix-logo-horizontal.svg`
- Primary logo (stacked): `clisonix-logo-stacked.svg`
- Monochrome dark variant: `clisonix-logo-dark.svg`
- Monochrome light variant: `clisonix-logo-light.svg`
- PNG export 1x: `clisonix-logo-horizontal-1x.png`
- PNG export 2x: `clisonix-logo-horizontal-2x.png`
- App icon base: `clisonix-icon-1024.png`

## Technical Requirements
- Source format must be SVG for all vector logos.
- PNG exports must preserve transparent background.
- Keep a safe area equal to at least 0.5x the icon height around the logo.
- Do not distort or recolor outside approved variants.

## Repository Target
Publish to:
- `https://github.com/BledjonaAhmati/clisonix-invest/tree/main/brand`

## Validation Checklist
- All required files exist and can be opened.
- SVG files render correctly in browser preview.
- PNG files are crisp at 100% and 200% zoom.
- File naming matches this spec exactly.

10. TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

❌ "Connection refused" on port 8030?
   → Make sure Ocean-Core is running: .\START_OCEAN.ps1

❌ "Command not found" on curl?
   → Use Invoke-WebRequest instead (PowerShell built-in)
   → Or install curl: choco install curl

❌ "Module not found" on python scripts?
   → Install requirements: pip install -r requirements.txt

❌ "Port already in use"?
   → Kill existing processes: Get-Process python | Stop-Process -Force

❌ Chat not working but API returns error?
   → Check ocean_api.py is running correctly
   → Check specialized_chat_engine.py is in ocean-core folder
   → Check ocean-core/__init__.py exists

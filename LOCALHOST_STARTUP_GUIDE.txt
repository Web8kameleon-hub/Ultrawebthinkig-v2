TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

❌ Port Already in Use?
   The scripts will check for available ports. If you get "port in use":
   
   Kill Python: Get-Process python | Stop-Process -Force
   Kill Node:   Get-Process node,npm | Stop-Process -Force

❌ Python Not Found?
   Make sure Python is in PATH:
   python --version
   
   If not:
   • Install Python 3.9+
   • Or use full path to python.exe

❌ npm Not Found?
   Make sure Node.js is installed:
   node --version
   npm --version

❌ Dependencies Missing?
   • For Backend/Ocean: pip install -r requirements.txt
   • For Frontend: cd apps/web && npm install

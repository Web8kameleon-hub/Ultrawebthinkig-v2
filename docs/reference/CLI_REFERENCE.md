# CLI Reference

## Core Commands

- `yarn ultra` : Launch full local platform.
- `yarn infra:validate` : Validate internal API + IoT topology contract.
- `yarn no-fake:audit` : Generate no-fake findings report.
- `yarn no-fake:enforce` : Block on no-fake violations.
- `yarn governance:docs:check` : Verify governance docs/checklist completeness.
- `yarn validate:delivery` : Run governance delivery baseline.
- `yarn release:check` : Run release readiness checks.

## Report Paths

- `reports/infra-topology-validation.json`
- `reports/no-fake-audit.json`
- `reports/release-readiness.json`

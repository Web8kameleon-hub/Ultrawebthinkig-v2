# Core Governance Package

## Purpose

Defines the constitutional governance baseline for Clisonix medical publication operations.

## Required documents

- `Clisonix Medical Governance Standard (GEN6-GEN9)`
- `Hard fail conditions and gates`
- `Error-rate continuum policy (0.001% to 0.50%)`
- `Reference metadata policy`

## Mandatory visual assets

- GEN6-GEN9 architecture diagram
- Publication gate flowchart
- Governance responsibility map

## Image policy for this package

- Architecture visuals may be generated and versioned.
- Decision-flow visuals may be generated from source diagrams.
- No fixed image reused across all versions.

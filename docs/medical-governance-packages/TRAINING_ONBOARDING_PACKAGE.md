# Training and Onboarding Package

## Purpose

Enables staff and contributors to apply governance standards consistently from day one.

## Required documents

- Role-based onboarding path
- Operator quick-start and SOP map
- FAQ and known failure patterns
- Competency checklist and certification steps

## Mandatory visual assets

- Role responsibility matrix
- Training journey map
- Failure recovery cheat sheet

## Image policy for this package

- Slides/diagrams can be generated and updated per release.
- Screenshots may be used only if version-stamped and replaceable.
- Evergreen fixed images without version are not allowed.

# Visual Communication Package

## Purpose

Transforms governance and protocol logic into clear visual language for operators, reviewers, and leadership.

## Required documents

- Layer icon system and naming rules
- Diagram grammar and legend standards
- Data flow visualization standards
- Visual QA checklist

## Mandatory visual assets

- End-to-end governance architecture map
- Data flow diagram (labs → governance → publish)
- Layer interaction map (GEN6-GEN9 + QC continuum)

## Image policy for this package

- Real imagery for physical systems is allowed with citation.
- Generated illustrations are preferred for conceptual architecture.
- Fixed banner-like images are forbidden for governance documents.

# Academic Publication Package

## Purpose

Ensures documents are publication-ready with academic integrity, structure, and citation discipline.

## Required documents

- Manuscript structure standard (IMRaD + limitations + disclosures)
- Citation and bibliography rules
- Metadata publication schema
- Authorship and contribution declaration rules

## Mandatory visual assets

- Methods workflow figure
- Results visualization standards guide
- Citation-provenance mapping diagram

## Image policy for this package

- Figures may be real plots or generated explanatory diagrams.
- Every figure must include provenance and version metadata.
- Figures without source/provenance are invalid for publication.

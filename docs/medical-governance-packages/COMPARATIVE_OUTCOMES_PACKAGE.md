# Comparative Outcomes Package

## Purpose

Defines consistent endpoint design, comparative analysis methods, and cohort-level interpretation standards.

## Required documents

- Endpoint specification handbook
- Comparative analysis methodology
- Cohort stratification and confounder policy
- Statistical interpretation and reporting rules

## Mandatory controls

- Primary/secondary endpoint declaration
- Cohort comparability checklist
- Bias and confounder adjustment log
- Standardized outcomes report format

## Required visual assets

- Endpoint hierarchy diagram
- Cohort comparison flowchart
- Outcome comparison plots guide

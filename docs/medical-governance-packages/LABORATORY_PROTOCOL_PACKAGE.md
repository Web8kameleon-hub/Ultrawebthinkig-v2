# Laboratory Protocol Package

## Purpose

Standardizes laboratory execution, QC controls, and biomarker handling across all participating labs.

## Required documents

- SOP master (sample handling, processing, reporting)
- Layered QC protocol (0.10/0.20/0.30/0.40/0.50)
- Continuous checkpoint protocol (0.001% to 0.50%)
- Unit normalization and reference-range rules

## Mandatory visual assets

- Sample flow diagram (collection → analysis → reporting)
- Instrument calibration workflow
- QC checkpoint matrix map

## Image policy for this package

- Real device/instrument images are allowed with source metadata.
- Generated process diagrams are recommended for SOP flows.
- Every image must be traceable to package version.

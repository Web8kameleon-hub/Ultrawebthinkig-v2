# Clisonix 30-Day Activation Plan (PartnerStack + Impact + Referral Program)

## Mode: Founder-Only (No Investors)
Operating constraints:
- Keep fixed monthly growth costs low
- Prefer performance payouts over fixed agency fees
- Focus on channels with measurable SQL and paid outcomes

## Objective
Launch a performance-first growth setup with:
1. PartnerStack
2. Impact
3. Clisonix own referral program (20-30% recurring, 6-12 months)

## Week 1: Foundations
- Finalize ICP definitions and accepted conversion events.
- Standardize UTM taxonomy.
- Ensure CRM fields exist: lead source, SQL status, paid date, MRR.
- Create partner policy and payout terms draft.
- Set monthly budget guardrails (starter: **€800-€2,500 total paid spend**).

### UTM Standard
- `utm_source` = partner name
- `utm_medium` = affiliate
- `utm_campaign` = offer/campaign name
- `utm_content` = placement/creative
- `utm_term` = optional keyword

## Week 2: Platform Setup
- Open and verify PartnerStack publisher/partner setup.
- Open and verify Impact setup.
- Publish Clisonix referral terms page.
- Configure tracking links and postback/webhook where possible.
- Activate referral landing page with clear recurring payout terms (20-30%, 6-12 months).

## Week 3: Offer + Content
- Build 2 partner offers:
  - Offer A: demo-driven
  - Offer B: paid-subscription driven
- Publish 2 educational assets:
  - "How to evaluate AI/B2B stack tools"
  - "Clisonix growth ops toolkit"
- Add clear affiliate disclosure.
- Recruit first 5-10 niche partners (small but aligned audiences > big generic traffic).

## Week 4: Optimization
- Review by partner/source:
  - qualified leads
  - SQL
  - paid conversions
  - MRR
- Remove low-quality sources.
- Increase placement for top EPC/top SQL partners.
- Prepare next 30-day test roadmap.
- Enforce stop-loss: pause any source with spend but no valid SQL signal.

---

## KPIs to Track Weekly
- Qualified Lead volume
- SQL volume and SQL rate
- Paid conversion count
- Cost per SQL
- Cost per paid customer
- Net new MRR
- Payback period trend

## Kill Rules (Fast)
Pause partner/source if any condition persists for 2 weeks:
- High volume but near-zero SQL
- SQL quality fails sales validation
- Missing attribution evidence
- Spend exceeds planned threshold without movement to SQL stage

## Scale Rules
Scale partner/source when:
- SQL quality stable >= target
- Paid conversions increasing
- Cost per paid customer within target band
- Early payback trend (self-funded target: <=4 months)

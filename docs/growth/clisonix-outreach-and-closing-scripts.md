# Clisonix Outreach + Closing Scripts (Copy/Paste)

## 1) First Contact (LinkedIn/Email)
Hi [Name],
I noticed [specific observation about their funnel/process].
I help founders fix this fast with a 48-72h AI automation/tracking sprint.
If useful, I can send you a short 3-point audit for your setup.
Open to that?

---

## 2) Follow-Up #1 (48h later)
Hi [Name], quick follow-up.
I recorded 2 concrete issues in your current flow that likely cost leads/revenue.
If you want, I’ll send them in one message and you can decide if it’s worth a short call.

---

## 3) Follow-Up #2 (Last touch)
Last message from me, [Name].
If improving [lead conversion / follow-up speed / tracking clarity] is a priority this month,
I can do a fixed-scope sprint with clear deliverables in 2-3 days.
If timing is bad, no worries.

---

## 4) Discovery Call Structure (15-20 min)
- Minute 1-3: objective + current bottleneck
- Minute 4-10: quantify pain (lost leads, slow process, no visibility)
- Minute 11-15: present one fixed-scope solution
- Minute 16-20: price, timeline, next step, payment

## 5) Offer on Call (Simple)
I recommend the [Starter/Standard] sprint.
- Scope: [exact deliverables]
- Timeline: [48-72h]
- Price: €[X]
- Start: today after upfront 50%
If that works, I’ll send the confirmation + payment link now.

---

## 6) Objection Handling
### “Too expensive”
Totally fair.
Let’s reduce scope to a starter sprint that solves the highest-impact bottleneck first.
You can upgrade only if the result is clear.

### “Need to think”
Of course.
What exactly do you need to validate: scope, timing, or ROI?
If useful, I can send a one-page plan with expected outcomes today.

### “No budget now”
Understood.
I can offer a lean version with only core implementation so you get outcome fast,
then expand once results start coming in.

---

- Deliverables: [X, Y, Z]
- Timeline: [date]
- Price: €[amount]
- Upfront: 50% to start

---

## 8) Referral Ask (After Delivery)
Happy this helped.
If you know 1-2 founders who need the same outcome,
I can prioritize them this week and give you a referral bonus/add-on.

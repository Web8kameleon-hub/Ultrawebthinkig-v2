# Clisonix Agency Scorecard (B2B SaaS Hybrid Model)

Use this scorecard to compare agencies before signing.

## Bootstrapped Founder Priority
When no investors are involved, prioritize:
- Low fixed cost
- Fast path to SQL and paid conversions
- Strict cash-burn control

## Scoring Method
- Score each category from 1 to 5.
- Multiply by weight.
- Highest total wins, but any red-flag category fails automatically.

## Red-Flag Auto-Fail
If any of these are true, stop evaluation:
- Refuses KPI definitions based on SQL/Paid/MRR
- Refuses CRM + UTM attribution transparency
- Demands long lock-in without pilot exit
- Won't operate in client-owned ad accounts
- Requires high fixed retainer (e.g., >€1,200/month) without strong performance component
- Refuses stop-loss rules and spend caps

## Interview Questions (Must Ask)
1. Which KPI do you optimize for in month 1, 2, and 3?
2. How do you define and validate SQL in CRM?
3. Show one example where you reduced cost per paid customer, not just CPL.
4. What is your attribution dispute policy?
5. What happens if pilot KPIs are missed at Day 60?
6. What is the absolute minimum monthly fixed fee you can accept for a 60-day pilot?
7. What stop-loss rule do you propose if no SQL appears in first 14 days?

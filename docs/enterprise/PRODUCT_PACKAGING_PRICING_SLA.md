# Product Packaging, Pricing, Contract SLA

## Product 1: Ocean Enterprise API
- Core value: multilingual enterprise assistant + orchestration + routing
- Includes:
  - Ocean chat APIs
  - service routing and integrations
  - enterprise guard hooks
- Base pricing:
  - Starter: €1,200/month
  - Growth: €3,500/month
  - Enterprise: custom
- SLA:
  - 99.95% availability (Growth+)
  - P1 response <= 30 min, workaround <= 4h

## Product 2: Trinity Analytics
- Core value: ALBA/ALBI/JONA insight layer + operational analytics
- Includes:
  - analytics endpoints
  - dashboards and telemetry exports
  - anomaly workflows
- Base pricing:
  - Starter: €900/month
  - Growth: €2,800/month
  - Enterprise: custom
- SLA:
  - 99.9% availability
  - scheduled reporting guarantees

## Product 3: Regulated AI Copilot
- Core value: governance-first copiloting for regulated workflows
- Includes:
  - policy checks and audit trail hooks
  - controlled routing and approvals
  - evidence artifacts for compliance
- Base pricing:
  - Starter: €1,800/month

  - Enterprise: custom + onboarding fee
- SLA:
  - 99.95% availability
  - audit evidence export within 24h on request

## Contract SLA Clauses (Minimum)
- Service definition and exclusions
- SLO targets and measurement source
- Incident severity matrix and response targets
- Data retention window and deletion process
- Security responsibilities (shared model)
- Change management and maintenance windows
- Termination + data export terms
